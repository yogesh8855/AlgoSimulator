# AlgoSimulator 

AlgoSimulator is an interactive algorithm visualization platform that helps students learn and understand algorithms through real-time simulations, animations, and step-by-step execution.

## Features

* CPU Scheduling Visualization

    * FCFS, SJF, SRTF, Round Robin, Priority

* Sorting Visualization

    * Bubble, Selection, Insertion, Quick, Merge

* Searching Visualization

    * Linear Search, Binary Search

* AI Search Visualization

    * BFS, DFS, A*

* Step-by-Step Execution

* Pseudocode Highlighting

* Performance Metrics

* Interactive Learning Experience

## Getting Started

### Backend

```bash
cd algo-sim-backend
mvn spring-boot:run
```

Runs on:

```text
http://localhost:8080
```

### Frontend

```bash
cd algosim-frontend-react
npm install
npm start
```

Runs on:

```text
http://localhost:5173
```
